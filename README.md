# Laura Paints and Creates

This repo contains the source code for <https://laurapaintsandcreates.com>.

## Development

To get started developing this site, clone the repo and run `npm run dev` in
your terminal.

## Architecture

This site is built using React, Typescript and Vite. It uses Tailwind CSS for
styling.

The site is hosted on GitHub Pages. There is a GitHub Actions workflow to
release on push to the default branch.

There is DNS configuration with the domain name provider to link up the domain
name to the GitHub Pages site.
